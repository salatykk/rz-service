# 🔐 RZ Service

**Супер-защищённые архивы ZIP и RAR, которые невозможно открыть без пароля.**

RZ Service — это комплект из двух программ для создания и открытия **непробиваемых архивов**:

| Программа | Назначение |
|---|---|
| **RZ Service** | Шифрование папки или файла в защищённый контейнер `.rzx` |
| **RZ unzip** | Просмотр и извлечение контейнера `.rzx` — только по паролю |

Файл-контейнер имеет собственный формат и **не распознаётся** ни Windows, ни WinRAR, ни 7-Zip — его невозможно открыть, распаковать или даже увидеть его структуру какими-либо сторонними средствами. Единственный способ получить содержимое — ввести правильный пароль в RZ unzip.

---

## ✨ Возможности

- 🗂️ **Шифрование целых папок и отдельных файлов**
- 📦 **Два внутренних формата:** ZIP (встроенный) или RAR (через установленный WinRAR)
- 🔒 **Шифрование данных по стандарту AES-256-GCM**
- 🛡️ **Защита пароля от перебора (Argon2id)**
- 👻 **Полное сокрытие структуры** — имена файлов и папок зашифрованы
- 🔍 **Проверка целостности** — повреждённый контейнер будет обнаружен
- 🎨 **Красивый тёмный интерфейс** в стиле современных архиваторов
- 📊 Индикатор стойкости пароля
- ⏸️ Отмена операции в любой момент
- 🗑️ Опциональное удаление исходных данных после шифрования

## 🚀 Быстрый старт

### Зашифровать (RZ Service)

1. Запустите `RZ Service.exe`.
2. Нажмите **«Выбрать папку…»** или **«Выбрать файл…»**.
3. Введите пароль дважды.
4. Выберите формат — **ZIP** или **RAR**.
5. Укажите, куда сохранить файл (расширение `.rzx`).
6. Нажмите **«Создать защищённый ZIP-архив»** / **«Создать защищённый RAR-архив»**.

Готово! Исходные данные превратились в один зашифрованный файл `.rzx`.

### Открыть (RZ unzip)

1. Запустите `RZ unzip.exe`.
2. Нажмите **«Открыть .rzx»** и выберите контейнер.
3. Введите пароль — только после этого программа покажет содержимое.
4. Выберите файлы и нажмите **«Извлечь выбранное»** или **«Извлечь всё»**.

## 🛡️ Почему это невозможно обойти

Обычный «зашифрованный ZIP» с паролем WinRAR может открыть — достаточно знать пароль или подобрать слабый. RZ Service устроен принципиально иначе:

1. **Данные сжимаются** в ZIP или RAR.
2. **Весь архив шифруется целиком** алгоритмом AES-256-GCM — без пароля нельзя прочитать ни байта, ни одного имени файла.
3. **Ключ выводится из пароля** защищённым от перебора способом — подбор пароля перебором практически невозможен.
4. **Итоговый файл имеет собственный формат `.rzx`** — он не похож ни на ZIP (`PK`), ни на RAR (`Rar!`), поэтому ни один сторонний архиватор его даже не распознает.

### Чего не сможет сделать никто без пароля

| Действие | Результат |
|---|---|
| Открыть в Windows / Проводнике | ❌ Файл не распознан как архив |
| Открыть в WinRAR / 7-Zip | ❌ Формат не опознан |
| Просмотреть структуру (имена файлов) | ❌ Всё зашифровано |
| Извлечь хотя бы один файл | ❌ Невозможно |
| Подобрать пароль перебором | ⚠️ Практически невозможно |
| Подменить/повредить данные незаметно | ❌ Любое изменение обнаруживается |

## 🔑 Рекомендации по паролю

- Минимум **8–12 символов**, лучше больше.
- Используйте **разные типы символов**: строчные, заглавные, цифры, спецсимволы.
- Не используйте имена, даты рождения и слова из словаря.
- Индикатор стойкости в программе подскажет уровень надёжности.
- **Запомните пароль или храните его в надёжном менеджере.** Восстановить забытый пароль невозможно — ни программа, ни кто-либо другой не сможет открыть контейнер.

## 🛠️ Сборка из исходников

### Требования

- Python 3.11+
- Windows 10/11
- Для формата RAR — установленный [WinRAR](https://www.win-rar.com/)

### Сборка

```powershell
# в корне проекта
.\build.ps1
```

Скрипт выполнит:
1. Создание виртуального окружения `.venv`;
2. Установку зависимостей из `requirements.txt`;
3. Прогон `selftest.py` — проверку криптоядра;
4. Генерацию иконки;
5. Сборку обоих исполняемых файлов в папку `dist\`.

### Запуск без сборки

```powershell
.\.venv\Scripts\python.exe app_service.py   # RZ Service
.\.venv\Scripts\python.exe app_unzip.py     # RZ unzip
```

### Структура проекта

```
RZ Service/
├── dist/                  # готовые .exe
│   ├── RZ Service.exe
│   └── RZ unzip.exe
├── rzservice/             # вспомогательные модули
│   ├── password_strength.py
│   └── uiutil.py          # форматирование размера/дат
├── app_service.py         # интерфейс RZ Service
├── app_unzip.py           # интерфейс RZ unzip
├── icon.png               # иконка программы
├── convert_icon.py        # конвертация icon.png в icon.ico
├── build.ps1              # полная сборка .exe (Windows)
├── make_secrets.ps1       # генерация секретов для GitHub Actions
├── .github/workflows/     # автосборка на Windows/Linux/macOS
└── requirements.txt       # зависимости
```

> **Примечание.** Криптоядро (модули `crypto.py`, `archive.py`) и тест `selftest.py` намеренно не включены в публичный репозиторий — внутренний формат контейнера остаётся закрытым.

## 🔄 Автосборка на Windows, Linux и macOS (GitHub Actions)

PyInstaller не умеет кросс-компиляцию: исполняемый файл собирается только на своей операционной системе. Чтобы получать готовые версии для всех трёх платформ без покупки Linux/macOS-машин, в репозитории настроен workflow `.github/workflows/build.yml`.

### Как это работает

1. При создании тега `v*` (например `v1.1`) или вручную (`Actions → Build executables → Run workflow`) запускается сборка на трёх runner'ах: `windows-latest`, `ubuntu-latest`, `macos-latest`.
2. Скрытое криптоядро **не хранится в репозитории** — оно восстанавливается из секретов GitHub прямо на runner'е прямо перед сборкой и попадает только в готовые бинарники.
3. Все бинарники выкладываются во вкладку **Release**.

### Настройка (один раз)

1. Локально сгенерируйте секреты:

   ```
   powershell -File make_secrets.ps1
   ```

2. В репозитории на GitHub откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте три секрета из вывода скрипта:

   | Имя секрета | Что содержит |
   |---|---|
   | `CRYPTO_PY` | `rzservice/crypto.py` (base64) |
   | `ARCHIVE_PY` | `rzservice/archive.py` (base64) |
   | `SELFTEST_PY` | `selftest.py` (base64) |

3. Создайте тег и запустите сборку:

   ```
   git tag v1.1
   git push origin v1.1
   ```

   Готовые файлы появятся в **Releases** (Windows: `.exe`, Linux/macOS: исполняемые файлы).

### Примечания по Linux и macOS

- **RAR-формат** требует установленного `rar`/WinRAR. На Linux/macOS он доступен только если установлен официальный `rar` CLI; без него программа корректно работает в режиме ZIP.
- **macOS**: бинарник не подписан, поэтому при первом запуске macOS может блокировать его (`unidentified developer`). Разрешить: правый клик → **Открыть**, либо выполнить в терминале `xattr -dr com.apple.quarantine "RZ Service"`.
- **Linux**: для запуска достаточно `python3-tk` на системе либо запуск из-под рабочего окружения с X11/Wayland.

## ❓ Частые вопросы

**Почему при выборе формата RAR программа просит установить WinRAR?**
Формат RAR — собственность WinRAR, и создавать его может только официальный инструмент. Программа использует `Rar.exe` из установленного WinRAR, но полученный RAR-архив всё равно зашифровывается целиком — WinRAR не сможет его открыть.

**Чем это лучше обычного ZIP с паролем?**
Обычный ZIP с паролем можно открыть в WinRAR/7-Zip и увидеть имена файлов. Контейнер RZ Service не распознаётся ни одним архиватором, а структура данных полностью скрыта.

**Можно ли открыть `.rzx` на другом компьютере?**
Да. Достаточно скопировать файл `.rzx` и программу `RZ unzip.exe` — открытие происходит только по паролю, привязки к компьютеру нет.

**Что если забыть пароль?**
К сожалению, открыть контейнер невозможно. Это обратная сторона настоящей безопасности: восстановить пароль не может никто.

**Windows пишет, что файл неизвестного типа. Это нормально?**
Да, это и есть защита. Файл `.rzx` не должен ассоциироваться ни с чем, кроме RZ unzip.

**Антивирус ругается на `.exe`?**
Однофайловые сборки PyInstaller иногда дают ложные срабатывания. Это не связано с вредоносным кодом — можно собрать свою копию из исходников (`build.ps1`).
